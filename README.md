# Database Performance Optimization Project

Designed and optimized an e-commerce database using PostgreSQL.

---

## Features

- Database Design
- Normalization
- Joins
- Indexing
- EXPLAIN ANALYZE
- Transactions
- Backup & Recovery

---

## Technologies

- PostgreSQL
- SQL
- pgAdmin

---

## Database Schema 

Customers | Products | Orders | OrderItems

---

## Performance Optimization

Created indexes on frequently queried columns and analyzed execution plans using EXPLAIN ANALYZE.

---

## Transaction Management

Demonstrated COMMIT, ROLLBACK, and SAVEPOINT operations.

---

## Backup and Recovery

Performed full database backup and restore using pgAdmin.
